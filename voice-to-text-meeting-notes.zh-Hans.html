用 Sono Note 把录音变成会议记录的步骤

  1. 选择模板：现成模板涵盖工作更新、客户通话、课堂、采访、医生就诊、创意、支持案例和项目回顾，第一次用就能得到有用的结果。
  2. 开始录音或直接开口说：一个想法、一堂课、一次客户通话或一段快速更新都可以；清晰、单一发言者的录音效果最清楚。
  3. 自动转录与整理：Sono Note 会把语音转成文字并整理，交给你一份完成的笔记，通常在你放下手机之前就已经完成。
  4. 检查内容：生成的文字请在使用前检查；遇到重要的地方，可以直接重播原始录音确认。
  5. 导出分享：以文本、Markdown 或 PDF 格式导出，随处分享。

隐私：仅本机模式与数据备份

笔记都存在你的 iPhone 上，无需账号、没有广告、没有跟踪。开发者没有自己的服务器，任何内容都不会上传给开发者。语音转文字使用 Apple 语音识别，部分语言可能会把音频发送给 Apple；切换到“仅本机”模式后，所有处理都留在你的设备上，飞行模式下也能使用。你可以把全部内容备份成一个带日期的文件并一键恢复，也可以在同一个地方浏览、重播、分享原始音频，或删除每一条录音。录下他人谈话前，请先取得对方同意。

常见问题

Sono Note 能把一整场会议录下来转成文字吗？

不购买时每条录音最长 3 分钟；通过 App 内一次购买解锁后，单条录音最长可达 3 小时。

没有网络也能录音转文字吗？

可以。切换到“仅本机”模式，所有处理都留在设备上，飞行模式下也能使用。

我的录音会上传到云端吗？

不会上传给开发者。Apple 语音识别在部分语言下可能会把音频发送给 Apple；选择“仅本机”模式则只在设备上处理。

上课做语音笔记、采访也能用吗？

可以。现成模板包含课堂、采访、工作更新、客户通话和医生就诊等场景。

笔记可以导出成 PDF 或 Markdown 吗？

可以导出文本和 Markdown；PDF 导出包含在 App 内一次购买解锁的功能里。

Sono Note 是订阅制吗？

不是。可以选择 App 内一次性购买解锁，没有订阅。
